Key commands
- npm run data:update       fetch StatFin 11rd + validate + regenerate baseline
- npm run data:build        rebuild from checked-in snapshot (offline)
- npm run data:validate     validate identities and provenance
- npm run test:data         test PxWeb parsing/query logic
- npm run dev               run Vite locally
- npm run build             validate + tests + TypeScript + Vite production build
